# Stocky 本地部署指南

如果您想在自己的电脑上运行这个应用，请按照以下步骤操作：

## 1. 环境准备
*   安装 [Node.js](https://nodejs.org/) (建议从 v20+ 开始)。
*   准备一个 **科学上网代理软件** (如 Clash, V2Ray 等)。

## 2. 安装依赖
在项目根目录打开终端 (Terminal)，执行：
```bash
npm install
```

## 3. 配置密钥 (.env)
1. 在项目根目录创建一个名为 `.env` 的文件。
2. 填入您的 Gemini API Key：
   ```env
   GEMINI_API_KEY=AIzaSy...你的真实密钥
   ```

## 4. 解决网络连接问题 (核心步骤)
由于 Gemini API 的服务器在海外，国内本地运行**必须**保证网络环境通畅。

### 方式 A：开启代理软件的 "TUN 模式" (强烈推荐 🌟)
这是**最稳定、最省心**的方式。
*   在您的代理软件（如 Clash Verge, Clash Meta, Stash 等）设置中找到 **"TUN 模式"** 或 **"虚拟网卡"** 并开启。
*   开启后，您的系统流量会自动接管，您只需在终端直接运行 `npm run dev` 即可。

## 5. 常见问题排查
### 模型 404 错误
如果报错 `404 Not Found`，通常是因为：
*   使用了错误的模型别名。本程序默认使用最新的 `gemini-3-flash-preview`。
*   如果您的 Key 比较旧，可以尝试在 `.env` 中设置 `GEMINI_MODEL=gemini-1.5-flash` 进行回退。

### API Key Invalid (密钥无效)
*   **请务必确认您创建了 `.env` 文件**（注意文件名开头有一个点 `.`）。
*   检查 Key 前后是否有空格或换行，只需填入一串乱码字符即可。
